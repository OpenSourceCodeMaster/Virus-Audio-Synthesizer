🛠️ OPTION 1: COMPILE WITH VISUAL STUDIO (RECOMMENDED / GUI WAY)
--------------------------------------------------------------------------------
You do not need to manually configure linker settings—all required Windows audio
and Media Foundation libraries are already linked via #pragma comment in the code.

1. Download and install Visual Studio (Community Edition is free).
   - During installation, check the workload: 
     "Desktop development with C++"
2. Open Visual Studio and click "Create a new project".
3. Search for and select "Empty Project" (C++ / Windows) and click Next.
4. Name your project (e.g., VirusAudioSynth) and click Create.
5. In the Solution Explorer (right panel), right-click "Source Files" -> 
   Add -> New Item -> C++ File (.cpp).
6. Paste the entire C++ source code from this repository into that .cpp file.
7. At the top toolbar, switch "Debug" to "Release" (optional, for cleaner builds).
8. Press Ctrl + Shift + B to build, or F5 to compile and launch!

   cl /EHsc /O2 /DUNICODE /D_UNICODE main.cpp user32.lib gdi32.lib
